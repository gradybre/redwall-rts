## Precision contract and remaining proof

The nine complete engine source files are pinned by reviewed constants in the
new Python tool, as well as by the downloaded source manifest. Refreshing the
manifest cannot authorize altered shader or mesh-packing code. The source is
the [official4.7.2 tag](https://github.com/godotengine/godot/tree/4.7.2-stable).
Both the offline Metal compiler and the runtime Metal driver select fast math.
The RD3D skin path reads binary32 vertices, decodes four/eight UNORM16 weights,
forms a weighted affine matrix and multiplies the position. Forward Clustered
also has a compressed-vertex decode and a separate instance/model path.

Apple's [Metal language specification](https://developer.apple.com/metal/Metal-Shading-Language-Specification.pdf)
is pinned by URL, date and exact digest in `precision-source.json`; the full
copyrighted PDF is not copied into the repository. Sections1.6.3 and8.1–8.5
allow reassociation, contraction and subnormal flushing, while bounding the
basic add/subtract/multiply/fma operations. The theorem uses a2^-23 rounding
unit to cover nearest-even and toward-zero, and separately retains2^-126
input/output flush errors. It does not rely on the cancelled result's magnitude.

For one four/eight-influence position component, fully expanding the source
expression gives16/32 terms of at most three factors and47/95 arithmetic nodes.
The absolute sum of products bounds all additions, including cancellation.
The usual gamma bound covers the same or smaller arithmetic tree after
reassociation, factoring or contraction. Every leaf/node flush gets an explicit
bound amplified by `(1+largest_operand)^degree`; all admitted operands are exact
stored binary32 values no larger than2^24. The complete absolute intermediate
bound stays below2^80. The tests retain a cancellation case where bounding by
the final answer would fail, alternate sequential/balanced orderings, mixed
signs, both influence counts and amplified flushed inputs.

This is deliberately an **expression contract**, not a theorem about arbitrary
compiler rewrites or materials. It still requires the exact emitted position
expression, source-input quantization/UNORM conversion and common root/model
composition to be closed against the actual Actor. Normal/tangent deformation
and material displacement must not silently enter the position path. The
original GL source-image metadata cannot be relabelled to claim these gates.

The next bounded slice must bind the actual RD mesh/palette/material path and
derive complete source-dependent input, skin, decode and model residuals; then
recompute every continuous body/tool/contact role and demonstrate native rendered
attachment, update and cleanup on Metal. Only a later reviewed immutable
publication can activate coherent1130/1133 consumers. Exact source drift still
refuses. Actual support, paid workpiece handling and staircase travel remain
separate requirements.
