# 1142 native handoff witness

The parent granted this additive harness while Geometry independently reviews
the frozen six-file offline packet. Its final native execution waits for that
review. None of those six files, their manifests, the eight current consumers,
the actual Actor, or the actual Content loader changes in this increment.

The witness replays the exact five-program episode: approach, accepted 128u
descent, supported half-turn/reposition, accepted 128u ascent, and retreat. It
uses the three pinned source images sequentially, releasing the prior Actor
and Content before decoding the next image. It retains one borrowed immutable
mesh/material set and one shared finite OpenGL WorldBasis table. This is a
diagnostic lifetime, not a runtime allocation or budget admission.

Each source interval is sampled at its endpoints and midpoint. Signed local
root ceil precedes the old gait's fixed quarter-turn. New handoff roots are
already in the fixed program frame; their interpolated heading rotates the
body palette but never that root. The native skeleton matrices, body instance
world transform and static held-tool world transform are checked against a
separate scalar equation. Complete root, heading and local palette values must
match at all four joins. An independent Python event oracle checks every phase,
including stationary-root intervals and the terminal row/row/share-zero case.

All 22 exact fixture prisms remain visible: fourteen timber parts and eight
natural bearing boxes. Side, opposite and RTS views include both directions,
all joins and the turn's previously rejected toe/deck locations. The figure is
an unpaid source fixture. It neither publishes physical support nor invokes
Work, Routes, Placement or authoritative movement.

The wrapper uses an output-specific user directory, create-only output and
same-file source hashing before import and after execution. It preserves raw
import/native logs, refuses any diagnostic/leak or source drift, checks exact
positive pose/join/matrix/PNG censuses and hashes every saved image. Actual
runtime input closure is recorded separately from historical source proofs;
an obsolete script pin must refuse rather than be silently reused.

This witness is restricted to the existing OpenGL backend. Default Metal,
native continuous enclosure, actual paid support and World playback, adopted
phase rate, save/lifetime integration and whole-client memory/performance
remain open. Source preview timing never supplies gameplay pace.
