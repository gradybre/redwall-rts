# Inhabited places — qualitative atlas and environmental direction

`DESIGN-ATLAS-002` · Revision 1.0 · These are source-supported relationships and authored modeling interpretations. None is a surveyed canonical map, a new world-generation preset or a metric building plan. Arrows below mean the stated relationship or narrative route; they do not establish distance, orientation or bidirectional access unless specified.

## 1. Brockhall: roots as a domestic structure

Evidence: MF-D04. This is the strongest furnished underground dwelling reference in this pass.

```text
root-fork entrance
        |
 descending passage -- study / sitting rooms / nursery / infirmary
        |
       hall -- hearth / board / alcoves
        |
        +-- left: sleeping rooms and dormitories
        +-- right: larder / kitchen / stores -- rear escape opening
```

Root beams, columns and fitted shelving retain their natural forms; baked clay lines surfaces; small seats and household furnishings establish use. Model the route first, then the room shell, then furniture and clutter. An artist must leave a real passage and working contact positions. The source supplies no ceiling height, stair pitch, soil load or ventilation calculation.

Game value: an earth-built home can be comfortable, spacious, old and cared for. Burrow building should express chosen habitation. Persistent rooms and routes support storage, care and everyday service under SET-MOVE-001; structural rules still require the exact construction contract.

## 2. Polleekin's home: accessible arboreal habitation

Evidence: MW-D03.

```text
rock outcrop + leaning dead oak trunk
                     |
               inclined approach
                     |
          room supported by three boughs
          [broad branch seat] [oven] [larder]
```

Driftwood, cordage, moss packing and woven foliage create a deliberately assembled home. A mole occupies it. Do not replace the sloping approach with a vertical squirrel-only climb. Source room construction is an art reference, not a real structural approval. Game geometry requires load, clearance and contact specifications.

## 3. Abbey: institution with ordinary and ceremonial rooms

Evidence: RW-D02/D06, LP-D03/D07/D08/D10, MX-D03, PL-D03, TR-D01/D02/D04.

| Layer/program | Source relationships | Feeling and asset direction |
|---|---|---|
| Grounds | Main path/gate/gatehouse; lawns, pond, gardens, orchard; wall walks | Welcoming enclosure and visible maintenance; seasonal flowers and work supplies |
| Everyday gathering | Cavern Hole, service access, close seating | Comfortable conversation, winter stories, smaller meals |
| Ceremony | Great Hall, stained glass, columns, tapestry, bells | Shared attention; can become quiet in dawn light |
| Household | Dormitories, infirmary, cupboards and stairs | Lived routine, linens, personal things, reachable services |
| Underused history | Upper stairs and attics; old objects; dark low rooms | Dust, quieter acoustics, light shafts and accumulated use |
| Buried history | Tunnel, shored platform, cavern and old castle rooms in Long Patrol | Former structures affect present maintenance; separate era-specific site configuration |

Marlfox's description gives a north–south path by the Abbey and woodland along north/east and part of south. Keep that qualitative statement tied to its era. Do not combine all novels' doorways, ruins and room changes into one allegedly exact canonical building.

## 4. Salamandastron: several meanings of stone

Evidence: LP-D04, SA-D05, OC-D01, LB-D02/D09/D10.

| Program | Model reference | System relationship |
|---|---|---|
| Domestic fortress | Halls, dormitories, kitchen, stores, family/readings, school/gardens in frame account | Household and civic work must fit alongside defense |
| Forge | Anvil, hearth, bellows, flue, hung weapons, daylight window | Work contacts, storage, heat/light presentation |
| Coastal access | Ledges, tunnel entrances, sea-facing rock | Explicit transitions and entry conditions |
| Forgotten approaches | Narrow passages, crawling, holes, water sounds | Body-plus-gear clearance; occupied access and queues |
| Ancestral chamber | Carved history, particular absences, personal response | Narrative site with attributed meaning; no automatic magic resource |

The domestic mountain is not a single static household throughout the series. Russano's frame and Brocktree's narrated era require different resident rosters. No source dimensions here justify giant residents or an expansion of the settlement population budget.

## 6. Required location brief

Before any location becomes a build task, supply its scenario era, actual inhabited purpose, residents/groups, approach, exits, work/service contacts, storage, light/sound, source IDs and declared deviations. Then use the project's scale and exact movement profiles to produce a measured game plan. Label the resulting dimensions `AUTHORED_GAME_GEOMETRY`; never `CANON_MEASURED`.

| Layout check | Required result |
|---|---|
| Home → food/store → work | Each promised function has a valid path for its intended occupants and loads |
| Entry and return | Climb/dive routes have supported endpoints and return policy |
| Overlapping floors | Separate identity, picking and transfers |
| Burrow → tunnel → deeper excavation | All methods share authoritative connectivity |
| Prop placement | No important doorway, contact or clearance envelope blocked by visual dressing |
| Alternative view | Cutaway preserves operational state and discoverable selection |
| Context | Art, narrator and UI distinguish home, work, memorial and abandoned site |
