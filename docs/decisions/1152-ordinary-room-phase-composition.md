# 1152 — Ordinary Room phase composition
Date: 2026-10-04 · Status: In progress

## Decision

Add `underground_room_world_bindings.gd` as the concrete ordinary Room phase
provider extending `EntryWorldBindings`, which already extends the actual
World composition. One Sites/SpatialAuthority binding serves both paths; the
new ordinary branch leaves the inherited exact Entry path intact. A Corridor
type alone does not establish a Placement or select entry permission. The provider consumes current
full Site, Room, Project, Job, worker, endpoint and source identities. It does
not preserve an admission witness as productive permission and does not create
a Connector Placement to obtain a phase publication token.

The implementation remains within the existing phase/Funding protocol.
BRACE, CUT and FINISH retain their adopted quantities, work, spoil and refund
rules. Unsupported backfill operations refuse explicitly. A Room confirmation
or a profile flag alone does not authorize work.

## Contact and source boundary

The proposed once-bound contact configuration names the actual WorldRoutes
owner, the actual WorkFace reader, one full already-existing retreat Location,
the explicit travel Profile ID/revision, and the original Placement issuer's
single borrowed phase context. Current assigned BUILD workers select their actual committed
work endpoint and Profile for START and productive work. Worker-free terminal
settlement must freshly resolve a unique current source-qualified contact for
the exact Site face; a missing or ambiguous contact refuses.

Plans include every source body/load, stance, stroke, approach and recovery
extent. Supported worker approach and the exact face reach are distinct from
the complete source motion envelope. A negative body extent cannot be clipped
away to avoid a wall or support intersection. Existing endpoint/route proofs,
fresh actual worker/tool/load facts, and current Terrain/retained-space facts
remain conjunctive requirements.

Materials, spoil and refunds use the actual passed Inventory container and
its full STORAGE Location. The current exact path to that endpoint and the
explicit retreat must qualify. A held first-pile promotion requires the real
GroundPiles lease; it cannot be treated as an existing storage endpoint.

The existing `WorkFace.solid_face_refusal` retains its solid-only contract.
A separate FINISH observation may inspect the exact paid same-Room UNFINISHED
target only under the actual Site/Project/operation/stage tuple. ADMIT may name
a null Project before the new FINISH Project exists, but only with exact live
paid CUT history; subsequent stages require the actual purpose-5 Project. Empty space,
foreign unfinished space, future support and a caller-supplied success flag
are not substitutes. The complete source contact/body/stance rules still run.

## Current qualification and lifecycle

Qualification uses checked addition of the exact once-bound Profiles and
Catalog content revisions, the once-loaded Levels revision, and non-restored
Location/Routes publication tokens. It does not sum rewindable bank revisions.
Locations restore clears its published token, making qualification unavailable
until a new publication. Either content reload, a changed WORK selector without
a Space revision, a foreign equal-number owner or integer overflow invalidates
the old proof. These tokens never replace current full source/owner/worker facts.

The new coordinator closes private-reader reuse with exact concrete Routes,
Profiles, Locations, SpaceOwner, Directory and WorkFace scripts. Actual World,
Terrain, Nodes and Buildings observations remain allowed, followed by direct
original-owner and physical final leaves. Missing original WeakRefs refuse
before dereferencing them. Worker-free COMMIT/CANCEL resolves and reproves a
unique current source contact, exact Project/Site, resources, retreat and sealed
companions; it does not require the released contributor to remain assigned.

The current productive occupancy contract conservatively requires every
living Resident to have a current full Routes physical selection, including
remote surface residents. The host must satisfy that contract with actual
published body/tool/cargo sources; a far-away position or absent source is not
permission to ignore an actor. An actual remote unregistered Resident regression
refuses and succeeds after actual removal. This is a host/profile activation
prerequisite, not a claim that the present one-Mole content covers the whole cast.

## Host initialization and teardown handoff

1. Retain the original World/core stores, immutable source owners, Budget,
   SpaceOwner/CoreSources and Terrain. Configure this provider before binding
   the sole SpatialAuthority, actual Sites and Router. Bind Authority/Sites
   reciprocally once.
2. Configure the actual RoomBindings/RoomOrders composition and bind the same
   Locations to those Orders and Sites. Bind actual WorldRoutes/Routes and
   Profiles to the original movement, equipment and Inventory owners. Existing
   WORK, retreat and STORAGE endpoints must already have real supported space.
3. Configure/bind the actual Placement issuer on those same owners, even when
   no Placement row exists. Retain the actual structural Scope and reader;
   mixed operation uses the existing EntryStructure ordinary fallback plus its
   exact immutable Frontier binding. Bind inherited phase Contacts only when
   an actual Entry source/contact composition exists.
4. At quiescence call `bind_room_phase_contacts(actual_world_routes, work_face,
   placements, full_retreat_location, travel_profile, travel_revision, 1024)`.
   The provider calls the existing once-only `placements.bind_phase_authority`
   and borrows that issuer's original context. It allocates no second context.

The host must retain provider, actual WorkFace, structural Scope/reader,
RoomBindings/Orders, Authority/Sites, Placement and any Entry Contacts for their
whole original World lifetime. Before retirement, finish or explicitly discard
each original cold operation through Authority/provider using the captured Site,
Room, Project, operation, stage, cold token, Space token and companion token.
No caller may clear once-bound private weak references to simulate a reset.
Whole-World owner retirement remains decision 1155's separately reviewed host
protocol; this provider does not add its own reset, duplicate World banks or a
per-Site retirement ledger.
