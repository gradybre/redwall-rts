## Packed owner and streaming lifetime

Each Placement has18 I32 fields: generation; Corridor slot/generation; Catalog
row; origin XYZ; rotation; base level; installed assembly count; current Project
slot/generation; entry section slot/generation; surface-anchor Location
slot/generation; opening head/count. Two I64 fields retain payload revision and
Corridor source revision. Present/retired bytes produce90 bytes per row.

Each internal opening row has8 I32 fields: parent Placement slot/generation,
Catalog opening ordinal, next row, target Room slot/generation and target
section slot/generation. Its I64 target source revision makes40 bytes. These
internal rows expose no independent public EntityRef. An exhausted opening
pool refuses the complete request; it never silently drops an authored target.

Each bank has256 bytes of source/header pins. Header15 is the canonical count
of active Project links, audited against the actual rows; it is not another
project list or receipt owner. Remaining global revision capacity must cover
every active terminal transition. ADMIT requires the current active count plus
two increments (attach and its eventual completion/cancellation); unrelated
register/retire mutations preserve those reservations. Terminal publication
consumes one increment and releases one reservation. Streamed active-at-MAX,
exhausted active payload revisions, or a mismatched active count refuse before
publication. This is the initial uncommitted VERSION1 schema, so no prior wire
version is silently changed.

Live and inactive banks
coexist. Their two free heaps use8(P+M) bytes; one reused byte-per-row audit uses
P+M. Capture and restoration stream through one bounded4096-byte window;
restoration validates the inactive bank before swapping. No full wire image is
retained during preparation, capture or restoration. These operations exclude
each other. The existing live bank remains byte-identical on decode refusal.

The conditional envelope is:

`2*(90P+40M+256) + 8*(P+M) + (P+M) + 4096 + 2048 + 8192`

That is `189P+89M+14848`, or108800 at the constructor ceilings P256/M512.
The 2048 is a fixed logical packet/control allowance;8192 is an explicit
provisional native reservation, not a measurement. Maximum grouping4760 and

identified152976 binding remainder. The remaining37368 must also admit the
actual adapter, frontier, other binding controls and native growth. No
