# 0064 — UI refinement has an explicit visual contract
Date: 2026-09-11 · Status: Accepted implementation design; visual sign-off pending

## Decision

[SET-UX-VIS-002](../ui_visual_refinement_amendment.md) is incorporated into the
UI owner and specifies42 requirements, complete surface/state recipes, explicit
presentation changes, four synthetic visual targets and23 acceptance cases.
[Task04.5](../tasks/04_5_ui_visual_refinement.md) executes it before the visual
pattern spreads to more screens. Task10 retains final-release qualification.

## Why

Brendan judged the first UI too basic and asked Astra to take design ownership
and provide stringent implementation requirements. The former brief allowed a
flat theme as a finished treatment. Source/screenshot review also found actual
visibility, roster, data-formatting, focus and scaling defects, not just missing art.

## Consequences

Use FOREST HUD/JOURNAL content, licensed serif headings, dark focus on paper and
amended content-sized panels while retaining authoritative rules and all unchanged
UI contracts. Reference images are not game screenshots or proof of real data.
Runtime, structural visual checks, accessibility and user sign-off remain distinct.
No paid assets, gameplay scope reduction, save change or movement closure is adopted.
