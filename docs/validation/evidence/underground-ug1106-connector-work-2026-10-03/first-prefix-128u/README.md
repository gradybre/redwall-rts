`edd562056b12f732fbf60f0536207ba2afd1dce650d19df552ecf1e75ff9cf81`.
It is not active content, a profile certificate, or playable completion. The
input copies preserve exact reviewed source facts; `input-sha256.json` records
their original paths. Run `python3 check_geometry.py` for the independent
integer overlap, paid-cube and side-station census.

128u descent tread T0, with an actual supported return. Their fourteen positive
