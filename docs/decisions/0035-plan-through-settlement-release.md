# 0035 — Plan through the complete settlement release

Date: 2026-09-09 · Status: Accepted for planning organization only

## Decision

Extend tasks 01–03 with a release roadmap, detailed world/command and movement
work (04/05), milestone cards 06–10, a requirement allocation, a movement decision
package and an intermediate first-playable evidence checklist. Begin independent
contract work alongside the executor's task 03. Track proposals, adoption,
implementation and verification separately.

## Why

The current status had no execution task beyond 03. A working stock model does
not create player commands, routes, legal work or a playable colony. Single-refuge,
adult-only, ground-only tests also cannot cover adopted scenario families,
dependents or connected underground/water/canopy life.

## Consequences

[The package](../planning/README.md) follows ARCH-MIG-006 while recovering missing
command/initialization/service prerequisites. Pull required starter service/gear
stores forward from 06 into 04 with one owner. UI, state serialization contracts
and measurements accompany systems instead of being deferred entirely to the
final tasks. The ground gathering checkpoint is intermediate. No gameplay
proposal, new numeric constant, movement gate or performance claim is ratified
by this organizational decision. Preserve executor work and historical evidence.
