Status: implementation in progress; structural source only, playable acceptance open.

The entry-owner and paid-handling work require actual immutable structural
content. The current production Catalog contains ground pace only. Previous
first-prefix tests serialize the real L0/T0 geometry alongside explicitly
synthetic worker profiles; those test builders are not production publishers.

Compile the pinned `first-entry-prefix-v1.json` into the existing Catalog,
Assemblies and Recipes wire formats. Preserve all fourteen complete timber
prisms and eight natural bearing volumes. One landing bill owns parts0–6 and
one tread bill owns parts7–13: 4 wood/32 work units and 1 wood/12 work units,
respectively. These are Brendan's wood-only rates. No rope, per-prism bill,
extra work, delivered material or installed structure is created by decoding.

The first publication uses the actual reviewed v4 profile source and unchanged
twelve ground pace rows. It authors no stair-family pace. Floor metadata is
derived from the two exact deck tops; its path endpoints use the reviewed
single-step sequence. The six-cube pocket contains a half-metre residual beyond
T0 which is never represented as floor. The sole opening is the128u near-edge
strip inside L0. The structural envelope contains the complete parts, bearings
and pocket, with clearance height derived from the full published body,
approach and recovery bounds. None of that metadata establishes current air,
footing, occupancy, paid excavation or a usable route.

The offline producer is create-only and reconstructs all three files for an
exact check. Inputs and output hashes are retained. Actual Godot readers must
load the packet against original generated-World owners and current profile
and level sources; decoding must leave gameplay stores unchanged. Independent
review and strict focused tests are required before integration acceptance.

six below-surface cuts. Actual DIG profiles provide a candidate top-face reach;
