# Transform saved-column validation: source questions, not an accepted contract

2026-09-20. Read-only discovery while Schedule validation completes. Candidate next owner15, version1, primary87552, no child extents, nine i32 columns in canonical order: bound_persistent_id,x,y,z,yaw,prev_x,prev_y,prev_z,prev_yaw. Each87552;3151872 packed bytes. No production edit authorized from this draft alone.

Source transforms.gd uses Directory-derived POSITIONED_BASE[kind]+typed_row, with nonreused persistent ID stamp. Constructor allocates nine full arrays and requires Directory. Pure validation must never construct it or a Directory. place accepts every int32 x/y/z/yaw and sets previous=current; advance rolls current into previous, set_yaw rolls yaw only. Therefore no map bounds, normalized yaw0..65535, current=previous, ground-only y or speed-delta constraints belong in this local image validator.

Binding zero means never placed/unbound; initialization/reset/unbind zero all eight poses. Public writers never store negative binding IDs. The plausible local rules are all nine exact extents, all binding IDs nonnegative, then every zero-bound row's eight poses zero. Every positive binding row admits all signed int32 pose values, including extrema and differing current/previous. Source does not expose bulk copy/restore yet; bound_count is category2 count of nonzero stamps, not number of current live Directory matches.

Existing tests explicitly destroy a placed resident directly through Directory, leaving the Transform stamp and pose until reuse/place. A successor in the same typed row but another Directory slot is correctly unplaced; place replaces its predecessor's stamp without increasing bound_count. Thus stale positive IDs and retained poses are reachable public states and must not be rejected merely because the current Directory no longer contains that ID. Saved-world provenance/cursor/identity reconciliation needs an explicit separate contract; no live Directory lookup belongs in a local predicate.
