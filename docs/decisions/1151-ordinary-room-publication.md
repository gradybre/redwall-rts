## Decision

Extend the existing Room admission leaves to an ordinary `RoomPlan` held by the
actual `UndergroundRoomOrders`. An ordinary Room does not fabricate an
`EntryPlan`, Corridor, Placement, endpoint or route. The accepted entry branch
retains its separate source and Corridor constraints.

The original request, privately copied complete plan, future Directory
candidate, full World/Room references, original Budget/token and exact
Space/Location/Route preparation tokens remain mandatory. Ordinary plan
comparison includes every scalar and every canonical cell. The actual future
Room type is used in both the prepared source row and the mirrored live
Buildings receipt. Existing retained Location and route payloads can only be
refreshed to the single new geometry revision.

Keep these signatures and the 80-byte caller-owned `Locations.RoomContext`:

- `FinalFacts.prepared_room_refusal(owner, routes, locations, orders, candidate,
  space_token, budget, cold_token, max_checks)`;
- `Owner.room_prepared_leaf_refusal` and `Owner.room_commit_preflighted`;
- `Locations.room_scope_leaf_refusal`, `room_prepared_leaf_refusal` and
  `publish_room_preflighted`;
- the existing Routes and WorldRoutes Room static publication methods.

No retained member, packed column, bank, capacity, schema or memory reserve is
added. Plan payloads and source/claim work are charged before the final scans;
publication borrows existing packets and swaps existing banks without copying.
Exact helper-frame evidence will accompany the frozen source.
