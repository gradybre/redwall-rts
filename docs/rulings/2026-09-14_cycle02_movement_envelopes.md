## Q1 — explicit measured-envelope convention

1. **Identity and authority.** Measure a versioned `(species key, stored life stage, mode, posture, equipment/cargo variant)` against reviewed geometry. Record source mesh, rig, clip and proportion revisions/hashes, local origin, +Y up/−Z forward, units (1024u/m), support datum and anchor-to-root offset. Bind actual gear/attachments and finite supported cargo shapes, not just carry mass. Missing combinations refuse; the presence of a rendered asset is not an admission proof. A qualified envelope can remain valid without its final presentation asset, consistent with MOVE-DEP-R03.
2. **Measure the complete sweep.** Include body, ears/tail, clothing, carried/stowed gear, cargo and any required support/rescue attachments over legal entry, travel, hold, turn, reversal, retreat and exit states. Include each permitted orientation and interpolation between poses, not just a rest-pose box or sampled frame endpoints. Record measurement method and its conservative interpolation/error bound. If the sweep cannot be bounded, that variant is not ready. Never make an unmeasured tail, load or turn disappear to pass a fit test.
3. **Quantize outward.** Offline/import measurement may use floating point; committed gameplay bounds are signed integer units. For each axis, `lo_u = floor(1024 * measured_min_m) - margin_u`, `hi_u = ceil(1024 * measured_max_m) + margin_u`. `margin_u` is an explicitly authored nonnegative integer per axis, covers the declared measurement error/safety allowance, and has provenance. Missing margin is invalid; explicit zero is acceptable only when the measurement owner establishes that no additional allowance is required. No hidden importer epsilon or height-derived margin. Use checked int64 arithmetic for differences/sums and reject out-of-range int32 outputs.
4. **Retain anchored map semantics.** A ground anchor `(cx,cz)` is the north-west corner `A=(512*cx,512*cz)`. Class `k` proves the cells of the square from A to `A+(512k,512k)` are passable; it is not a centred radius. For the quantized swept local bounds and a fixed declared offset `o=(ox,oz)`, require:

   `ox+xlo >= 0; oz+zlo >= 0; ox+xhi <= 512*k; oz+zhi <= 512*k`.

   Boundary tangency is allowed by this containment test; penetration is not. The explicit margin determines any requested separation. Subject to the lower-bound tests, derive the least class as `k=max(1,ceil_div(ox+xhi,512),ceil_div(oz+zhi,512))`, and reject `k>512`. Nonnegative checked integer ceiling division is `(n+511)//512`. Also prove root/map validity and actual support. `ceil(max(width,depth)/512)` is only a lower bound and never replaces offset containment.
5. **Baseline placement remains +256/+256.** Apply the current root offset `(256,256)` to the existing cell-centre route representation. If either translated minimum is negative, **no larger class repairs that placement**. Return an explicit placement incompatibility, separate from absent measurements. Do not silently re-centre a k-square, clamp bounds or relocate a resident. A proposed different offset can be measured and reported, but its production use requires a reviewed G02 placement contract covering route-anchor identity versus root-containing cell, start/goal lookup, transforms, contacts, picking, interpolation, map edges and versioned save semantics. The formula above accepts that future explicit offset without changing map clearance meaning; this ruling grants no such migration.
6. **A square test is necessary, not a complete route proof.** At actual cell anchors require `_clearance[cell] >= k`. Additionally test the swept solid along full orthogonal/diagonal segments, corners and changes of direction against obstacles and support. For doors/tunnels/branches/shore transitions use the actual three-dimensional opening, height, slopes/steps, supported posture, turns and both directions. An AABB width/height comparison alone does not prove a bend, landing or diagonal legal. Missing vertical/support geometry is not infinite clearance. No arbitrary step, yaw/turn timing, separation radius or speed is assigned here.
7. **Commit and invalidate together.** Publish measurements as revisioned immutable profile content. Admission selects a matching profile from the resident's real species/stage and committed inventory state; it cannot accept caller-supplied synthetic clearance as production authority. Capture profile/contact/topology/load revisions; revalidate future edges before entry and preserve occupied recovery semantics under HAZ-005. Profile/source changes invalidate dependent qualifications. G02 owns packed storage, compiled domains, capacities, identity changes and save handling; this convention assigns no new binary enum or schema number.
